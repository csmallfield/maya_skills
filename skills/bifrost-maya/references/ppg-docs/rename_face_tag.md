# Rename Face Tag
Renames the faces specified via tag expression and sets new tags for them.

## Inputs

### Mesh
The input geometry.

### Tag Expression
Loads all faces that match this face tag expression(s).

### Replace This String
Search for this string in existing names and replace it with "New Face Tag".<br>
Leave this field empty to just overwrite existing names.

### New Face Tag
New face tag (or replacement for above search string).
