# Supplied PPG written documentation

Use these files for control semantics; use the compound interface index and actual exports for exact ports and numeric modes. All 34 files were extracted unchanged from the user-supplied `docs.zip`. They are separate from the older normalized compound documentation.

Start with `PPG_multi_cut`, `PPG_sequence_cut`, `get_face_info`, `PPG_extrude`, `create_pattern`, and `PPG_instance` for the building workflow. See [ppg-building-design.md](ppg-building-design.md) for the applied design and its trade-offs.

Retain original spelling and tutorial links as source text. A linked tutorial is not a retrieved transcript; no video transcript was reviewed in this case.
