# maya_skills

Claude skills for Autodesk Maya.

- `skills/bifrost-maya` - Bifrost graph design, debugging and native compound JSON, with an exact node index built from the installed Bifrost 3.0 library. Ported from an earlier ChatGPT (Astra) skill.

Install by linking a skill folder into `~/.claude/skills/` (Windows: `mklink /J "%USERPROFILE%\.claude\skills\bifrost-maya" skills\bifrost-maya`).
